# ESP32-S3 GPIO Map
> Preliminary GPIO allocation
> Assignments are subject to change during peripheral integration
> 'hardware_config.h' remains as the firmware source for GPIO mapping

## Planned Peripheral Assignments

| GPIO | ASSIGNMENT | COMPONENT | DIRECTION | INTERFACE | NOTES |
|---:|---|---|---|---|---|
| GPIO4 | MIC_BCLK | INMP441 | OUTPUT | I2S | Bit clock generated by ESP32-S3 |
| GPIO5 | MIC_WS | INMP441 | OUTPUT | I2S | Word-select / left-right clock |
| GPIO6 | MIC_DATA | INMP441 | INPUT | I2S | Digital microphone audio data |
| GPIO7 | LED_DATA | WS2812B | OUTPUT | Digital | Routed through SN74AHCT125 to 5V LED logic |
| GPIO8 | BME280_SDA | BME280 | Bidrectional | I2C | Sensor data |
| GPIO9 | BME280_SCL | BME280 | OUTPUT | I2C | Sensor clock |
| GPIO10 | MIC_MUTE | Toggle Switch | INPUT | GPIO | Manual microphone override |
| GPIO11 | CLOUD_ENABLE | Toggle Switch | INPUT | GPIO | Cloud override |

## Reserved Interfaces
| GPIO | RESERVED FOR | REASON |
|---:|---|---|
| GPIO17 | Raspberry Pi UART TX | U1TXD (Reserved for optional ESP32 to Pi UART) |
| GPIO18 | Raspberry Pi UART RX | U1RXD (Reserved for optional Pi to ESP32 UART) |
| GPIO19 | Native USB D- | Used by ESP32-S3 native USB interface |
| GPIO20 | Native USB D+ | Used by ESP32-S3 native USB interface |
| GPIO43 | UART0 TX | Preserve USB to UART programming/debug console |
| GPIO44 | UART0 RX | Preserve USB to UART programming/debug console |
